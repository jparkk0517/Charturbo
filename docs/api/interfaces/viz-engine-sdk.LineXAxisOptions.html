    Tick label text. Line x ticks receive the series x value (or the sample index without x), bar x ticks the bar / category index, y ticks the data value (percent for 'percent' bar charts). Time x ticks also receive the calendar boundary the tick lands on; the line tooltip calls it without one. Also a number format spec ('.2f', ',.0f', '.1%', '.2s', '$,.2f', 'compact', 'bytes') or Intl.NumberFormatOptions (chart-format.ts), compiled once for the chart locale (time axes: the spec formats epoch ms as a number).
