    Optionalbrush

    brush?: false | BrushMode

    Brush / box selection on 2D charts (mouse): 'x' selects an x interval (time range), 'xy' a rectangle (bars always brush x). While enabled, drag draws the brush and Alt + drag pans; wheel zoom and double-click reset keep working. Release emits 'select'; Escape or a click clears it.
