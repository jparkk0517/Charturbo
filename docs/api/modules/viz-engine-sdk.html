    Module viz-engine-sdk

    Main entry of the viz-engine-sdk package: VizEngineSDK (one chart or 3D graph per canvas), VizDevice (shared GPU device for many charts), themes, formatters and every public type. The WebAssembly module loads from viz_core_bg.wasm next to this module (see setWasmSource; viz-engine-sdk/inline embeds it). Excludes all demo UI / Studio / Game / Benchmark screens.
