    appendSeriesData

    • appendSeriesData(
          seriesIndex: number,
          values: number[] | Float32Array<ArrayBufferLike>,
          x?: number[] | Float64Array<ArrayBufferLike> | Date[],
          options?: AppendSeriesOptions,
      ): number

      Streams samples onto the end of one line series (live data). x (required iff the chart has x) must not go back before the series' last x. With maxPoints the oldest samples beyond it are dropped and ids are re-based. Amortized O(appended) in the engine plus a rebuild of the visible window on the next frame; the SDK keeps no copy of streamed data (tooltips / a11y read it back from the engine). Returns the new sample count.
