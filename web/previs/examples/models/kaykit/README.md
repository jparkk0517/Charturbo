# KayKit models (CC0)

3D models by Kay Lousberg (KayKit), https://github.com/KayKit-Game-Assets, license CC0 (Creative Commons Zero, http://creativecommons.org/publicdomain/zero/1.0/). The license texts of the three packs are in this folder (`LICENSE-*.txt`). Crediting is not mandatory. The files are unmodified copies of the pack files; they are used by `../../textured-demo.gen.ts` (`textured-demo.json`) and the textured pass of `../../gate-raid.gen.ts` (`gate-raid.json`).

| Pack | License file | Files |
| --- | --- | --- |
| KayKit Character Pack: Adventurers 1.0 | `LICENSE-adventurers.txt` | `axe_2handed.gltf` + `axe_2handed.bin` + `barbarian_texture.png`, `sword_1handed.gltf` + `sword_1handed.bin` + `knight_texture.png` |
| KayKit Character Pack: Skeletons 1.0 | `LICENSE-skeletons.txt` | `Skeleton_Minion.glb`, `Skeleton_Warrior.glb` |
| KayKit Dungeon Remastered 1.0 | `LICENSE-dungeon.txt` | `floor_tile_large.gltf.glb`, `pillar.gltf.glb`, `wall.gltf.glb`, `wall_gated.gltf.glb` |

The `.gltf` files reference their `.bin` and texture PNG by relative path; the `.glb` files are self-contained.
